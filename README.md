# kjartanvandriell.github.io

Source for my personal website, https://kjartanvandriell.github.io.

Built with Jekyll on the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template, itself based on the [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) theme (both MIT licensed, see `LICENSE`).

## Running locally

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```

The site is then served at http://localhost:4000. A Docker setup is also included (`docker compose up`).
